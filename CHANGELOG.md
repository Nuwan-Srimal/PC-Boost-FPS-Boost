## [2.0.0] - 2025-08-07

### Added
- ⚡ Lightning-themed dark UI with golden accents
- 🎨 Complete rounded corner design system
- 🪟 Custom window management (minimize/restore/close)
- 🧰 Comprehensive optimization toolbox:
  - System cleanup
  - FPS boost
  - CPU optimization
  - Visual tweaks
  - Services manager
  - Ultimate Performance power plan
- 📊 Real-time system monitoring:
  - Memory usage tracking
  - Disk space monitoring
  - CPU performance metrics
  - Process counting
- 🛡️ System protection tools:
  - Windows Defender status
  - Firewall monitoring
  - Update tracking
- 🎮 Gaming optimization features
- ⌨️ Keyboard shortcuts (Ctrl+M, F11, Alt+Tab)
- 📱 Responsive multi-page navigation
- 💬 Built-in feedback system
- 🔧 Settings and configuration panel

### Features
- **Home Page**: System overview with health check and boost cards
- **Protection**: Security status and management tools
- **Storage**: Disk management and cleanup tools
- **Apps**: Application management and quick uninstall
- **Toolbox**: Complete optimization tool suite
- **Settings**: Appearance and performance configuration
- **Feedback**: User feedback and support system

### Technical
- Built with Python 3.13 and Tkinter
- PyInstaller executable packaging
- psutil for system monitoring
- Multi-threaded operations
- Robust error handling
- Modular architecture

### UI/UX
- Modern dark theme (#1a1a2e background)
- Golden lightning bolt branding (#FFD700)
- Smooth hover effects and transitions
- Draggable title bar
- Custom minimize/restore popup system
- Professional rounded corner styling

### Performance
- Lightweight 11MB executable
- Fast startup time
- Responsive interface
- Efficient system resource usage

### Known Issues
- Windows Defender may flag unsigned executable
- Some features require administrator privileges
- Custom window management needed due to borderless design
